# data_analisys_and_aritficial_intellegence_tasks_2_year_of_study

Выполненные задания дисциплины под названием "Анализ данных и искусственный интеллект".

Для того чтобы запустить результат задания, необходимо:

1) Открыть папку задания в терминале. (Правой кнопкой мыши по папке и кнопки open in → Terminal или можно открыть с
помощью команды cd tasks_third_semester и cd task2_1)

2) Написать команду ".\ins.bat", чтобы установить виртуальное окружение в папке .venv с необходимыми для задания
библиотеками

3) Написать команду ".\act.bat", чтобы запустить результат задания.
